# CityDrive

Original unofficial browser driving demo. Static-host ready for GitHub Pages.

## Controls
WASD / Arrow Keys to drive. Space to brake. Touch controls are available on small screens.

## Deployment
Publish the repository root. No build step is required.

## Monetization
Use only approved advertising-provider code and clearly labeled ad areas. Do not use deceptive buttons, forced clicks, or misleading claims.
